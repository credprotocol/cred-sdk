# Security policy

## Reporting a vulnerability

Please report security issues privately, not in a public issue:

- **GitHub:** use [Report a vulnerability](https://github.com/credprotocol/cred-sdk/security/advisories/new) on this repository (private vulnerability reporting), or
- **Email:** security@credprotocol.com

Include the affected package and version, a description of the issue, and steps to reproduce if you have them. We will acknowledge your report within 3 business days and keep you updated until it is resolved.

## Scope

This repository covers the client SDKs: `@cred-protocol/sdk`, `@cred-protocol/hono`, `@cred-protocol/express`, `@cred-protocol/nextjs` (npm) and `cred-protocol` (PyPI). Issues in the Cred Protocol API itself can be reported the same way.

## Supported versions

Security fixes are released for the latest published version of each package.
